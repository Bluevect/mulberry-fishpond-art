# 暂定需求（可能继续更新）

## 创意研究点

极端天气（台风、洪涝）冲击下广东顺德大汕岛渔业生态的脆弱性，以及对传统“桑基鱼塘”模式的保护。厄尔尼诺对广东的影响并非简单的“多雨”或“少雨”，而是加剧极端性，并且与厄尔尼诺的类型（东部型/中部型）密切相关

## 实景图

位于 `/public/assets` 中

## 作品拟传达的内容、观念及拟命名

拟命名：水盈与韧性：大汕岛渔业的生态回响

通过可视化的灾情数据与动态桑基鱼塘循环模型对比，揭示传统渔业面对极端气候的脆弱性，反思并呼唤保护传统生态农业。
