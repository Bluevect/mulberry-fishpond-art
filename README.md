# 顺德桑基鱼塘 · 长卷叙事

一个以《清明上河图》式长卷为视觉原型的研究型网页：**极端天气（台风、洪涝）冲击下广东顺德大汕岛渔业生态的脆弱性，以及传统「桑基鱼塘」模式在当代生态抗灾中的启示。**

[网页链接](https://bluevect.github.io/mulberry-fishpond-art/)

## 快速开始

```sh
pnpm install
pnpm dev        # 本地调试
pnpm build      # 类型检查 + 生产构建
pnpm test:unit  # 单元测试
pnpm lint       # oxlint + eslint
pnpm format     # oxfmt
```
